# چرخ و فلک | Charkh o Falak

افزونه رایگان Chrome با رابط فارسی برای کار با Google Flow

## نصب از بسته ZIP افزونه

1. ZIP مخصوص نصب را استخراج کنید.
2. در Chrome، `chrome://extensions` را باز کنید و Developer mode را روشن کنید.
3. گزینه Load unpacked را بزنید و پوشه‌ای را انتخاب کنید که مستقیماً `manifest.json` دارد.
4. از پنل افزونه، آن را روشن کنید و اگر تب Google Flow از قبل باز است آن را دوباره بارگذاری کنید.

## سازگاری

سازگاری و استفاده از Google Flow تابع شرایط و سیاست‌های ارائه‌دهنده است.

## مسئولیت‌پذیری

هیچ داده‌ای از حساب کاربران برای پروژه گردآوری نمی‌شود، طبق بررسی ایستای کد همین نسخه. این جمله به معنی تضمین نبود تمام آسیب‌پذیری‌ها نیست. برای جزئیات به `docs/PRIVACY.fa.md` و `docs/SECURITY.fa.md` مراجعه کنید.
