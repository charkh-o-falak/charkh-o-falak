# Privacy — Charkh o Falak 1.1.0

Static inspection of this release found no collection of users' account data for the Charkh o Falak project, nor developer-operated account signup or analytics. IP and country are not displayed by the popup.

Google Flow and Telegram operate under their own privacy policies; the Telegram channel opens only when selected by the user. This description is based on the supplied source and is not an independent security guarantee.
