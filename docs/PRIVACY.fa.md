# حریم خصوصی — چرخ و فلک 1.1.0

بر اساس بررسی ایستای سورس این نسخه، افزونه برای پروژه چرخ و فلک اطلاعات حساب کاربران را جمع‌آوری نمی‌کند و سرویس ثبت‌نام، تحلیل رفتار یا ارسال اطلاعات حساب به سرور پروژه ندارد. در پنل افزونه نیز IP و کشور نمایش داده نمی‌شود.

استفاده از وب‌سایت Google Flow تابع سیاست‌های حریم خصوصی و شرایط Google است. لینک کانال تلگرام فقط با اقدام کاربر باز می‌شود و سیاست‌های تلگرام مستقل است.

این توضیحات نتیجه بررسی کد عرضه‌شده است، نه گواهی امنیت یا تضمین نبود آسیب‌پذیری.
