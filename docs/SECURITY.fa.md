# امنیت — چرخ و فلک 1.1.0

افزونه برای کار با Google Flow طراحی شده و در Chrome مجوز `scripting` و دسترسی به `https://flow.google.com/*` را درخواست می‌کند.

تعامل افزونه با اسکریپت‌های صفحه ممکن است با برخی اسکریپت‌ها یا تغییرات آینده Google Flow ناسازگار شود. همچنین پیام‌های مبادله‌شده در محیط همان صفحه احراز هویت مستقل فرستنده ندارند و امکان ارسال پیام مشابه توسط اسکریپت‌های دیگر همان صفحه وجود دارد. غیرفعال‌کردن افزونه لزوماً اثر آن را در تب از قبل بازشده فوراً از بین نمی‌برد؛ تب را دوباره بارگذاری کنید.

این نسخه ممیزی مستقل امنیتی یا تأیید رسمی Chrome Web Store ندارد. اطلاعات حساس مانند رمز عبور، کوکی یا توکن را در گزارش‌های عمومی خطا منتشر نکنید.
