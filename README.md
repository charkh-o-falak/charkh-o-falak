# Charkh o Falak

Free Chrome extension with a Persian interface for Google Flow.

## Install from the extension ZIP

1. Extract the extension ZIP.
2. Open `chrome://extensions` in Chrome and enable Developer mode.
3. Select **Load unpacked** and choose the folder containing `manifest.json` directly.
4. Turn on the extension from its popup. Reload any Google Flow tab already open.

## Compatibility

Compatibility and use of Google Flow depend on the provider's terms and service availability.
